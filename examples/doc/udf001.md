# udf001 — Thread 遍历

本示例展示如何使用 `DEFINE_ON_DEMAND` 遍历 Fluent 中的 cell thread 和 face thread。

## 文件

`examples/src/udf001.cpp`

## 编译

先将 `src/` 中已有文件移除，再把 `udf001.cpp` 复制到 `src/`，然后执行：

```sh
xmake build libudf
```

编译后将 `build/<平台>/<模式>/libudf/` 中的 `libudf.dll` 加载到 Fluent。

## 运行

在 Fluent 中加载 UDF 后，执行 on_demand 函数。输出中可以看出：

- `face_thread` 对应 Boundary Conditions 中的边界区域
- `cell_thread` 对应 Cell Zone Conditions 中的区域
